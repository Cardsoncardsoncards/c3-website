Core Set 2019 landed on 13 July 2018, one of the last of Wizards' old-style annual core sets before the format shifted again. It mixed reprints with new mythics and planeswalkers, and gave the format a run of cards that have held varying degrees of value in the years since. This list ranks the 20 most expensive cards from that set by current price in Australian dollars, counting down from number 1 to number 20.

Where a card has more than one printing within Core Set 2019, the ranking uses whichever printing carries the highest price. If two printings happen to land on exactly the same price, that tie is noted rather than quietly resolved one way or the other. As it happens, every card on this particular list has just a single priced printing in the set, so there are no ties or printing gaps to untangle here, just one number per card.

Prices shown are a snapshot only. Magic singles move constantly with reprints, supply and shifts in what people are actually buying, so the figures here reflect a moment in time rather than a fixed value. Treat the ranking as a guide to relative standing within the set rather than a forecast of where any card will sit next month.
