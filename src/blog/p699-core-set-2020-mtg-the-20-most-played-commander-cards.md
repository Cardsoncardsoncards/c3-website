Core Set 2020 landed on 12 July 2019, one of the last of the old-school core sets before Wizards moved away from the yearly format for a while. It gave Commander players a run of scry lands, a fresh cycle of Temples, and a handful of colourless utility pieces that have stuck around in decks ever since. This list ranks the twenty most played cards from the set in Commander, using EDHREC rank, where a lower number means the card shows up in more decklists.

Each card on this list appears once, even if it had more than one printing within Core Set 2020. Where a card had several printings, we used the lowest (best) EDHREC rank to place it, and the highest priced printing to set the headline figure shown above each entry. If two printings landed on exactly the same price, that tie is called out rather than quietly resolved. As it happens, every card here had only a single priced printing in this set, so the methodology mostly stayed in the background this time.

Prices are in Australian dollars and are a snapshot only. Singles markets move week to week, sometimes day to day, so treat the figures printed above each entry as a point in time rather than a fixed number. You can shop these through the card pages on our own site or through eBay Australia, and it is worth checking both before buying.
